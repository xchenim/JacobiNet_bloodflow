# Contributing

Thank you for your interest in JacobiNet Blood Flow.

## Before opening an issue

- Search existing issues first.
- Use the bug-report template for reproducible failures.
- Do not post private datasets, credentials, or security-sensitive details.

## Pull requests

1. Create a focused branch from `main`.
2. Keep changes small and document their scientific motivation.
3. Add or update tests for behavioral changes.
4. Run the documented tests and formatting checks.
5. Update configuration and reproduction notes when results change.
